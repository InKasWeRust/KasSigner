# Waveshare ESP32-S3-Touch-LCD-2 — Printable Case

3D-printable enclosure for the KasSigner Waveshare target, with a cradle
for a LiPo 602030 battery.

- Snap-fit closure — no screws.
- USB-C and button access; reinforced walls for daily carry.
- Simple PLA print; tolerances chosen for common FDM printers.

## Files

| File | Purpose |
|---|---|
| `ESP32-S3-Touch-LCD-2-Rev3-EnclosureButton_Stab_Sockets_v12.stl` | Print-ready mesh (binary STL, 13,524 triangles) |

The editable CAD source (Fusion 360 `.f3z` / STEP) is available at the
design's home page below; it is not vendored here to keep the repository
lean.
