Oracle Attest

Show the covenant request, then the oracle scans it under Single Signature → Covenant Sign. KasSigner independently recomputes this covenant's exact 32-byte commitment and verifies the isolated key is bound in the script before signing.

Optional beacon: the oracle deposits 0.1 KAS into this covenant with the attestation attached. It never spends covenant funds; the 0.1 KAS remains claimable/refundable.
